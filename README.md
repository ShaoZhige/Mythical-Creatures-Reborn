将 MLP Mythical Creatures (1.7.10) 移植到 Minecraft 1.20.1 Forge 并全面革新。

## 配置系统 / Config

配置文件位于 `config/mythicalcreatures/common.toml`，采用极简覆写格式：

```toml
overrides = [
    ["mythicalcreatures:bear", "max_health", 80.0],
    ["global_params", "cutie_mark_slots", 2],
    ["equipment:mythicalcreatures:twilight_sword", "attack_damage", 12.0]
]
```

支持实体属性、装备属性、耐久度、全局参数的全面自定义。
